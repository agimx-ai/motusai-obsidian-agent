# MotusAI Agent

[English](README.md) · 简体中文

在 Obsidian 中直接使用 MotusAI Seed，与你的笔记、文件和想法一起工作。

[官方网站](https://motusseed.com) · [最新版本](https://github.com/agimx-ai/motusai-obsidian-agent/releases/latest)

> 需要使用 Obsidian 桌面版，并在 [MotusAI Seed](https://motusseed.com) 中启用官方 **Agent Harness** 插件。

## 你可以做什么

- 不离开 Obsidian，即可对话、处理任务或完成持续推进的目标。
- 使用仓库中的笔记、文件和选中的预览内容作为上下文。
- 查看工具执行过程，并在敏感操作运行前进行确认。
- 在 MotusAI Seed 已配置的模型之间切换。
- 在每个仓库中继续之前的对话。

## 开始使用

1. 启动 MotusAI Seed，并启用 **Agent Harness**。
2. 在 Agent Harness 中配置模型。
3. 从 Obsidian 社区插件中安装并启用 **MotusAI Agent**。
4. 从侧边栏图标或命令面板打开 MotusAI Agent。
5. MotusAI Seed 请求授权时，确认本地连接。

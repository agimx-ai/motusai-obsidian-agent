## 通过 MotusAI Seed 与你的仓库协作

在 Obsidian 中直接对话和处理任务。以笔记、文件和选中的预览内容作为上下文，同时掌控每一次操作。

## 主要功能

- 用 Excalidraw 生成手绘流程图、思维导图和示意图，并在内置编辑器中打开和修改。
- 根据需要选择**聊天**、**工作**或**目标**模式。
- 无需离开仓库，即可引用笔记、文件和文件夹。
- 标注选中的预览内容，并随消息一起发送。
- 查看工具执行过程，并在敏感操作运行前进行确认。
- 切换已配置的模型，并继续之前的对话。
- 将本地笔记或整个文件夹分享为网页，自动生成目录并选择主题。

## 开始使用

1. 从 Obsidian 社区插件中安装并启用 **MotusAI Agent**。
2. 启动 [MotusAI Seed](https://motusseed.com)，然后添加并启用 **Agent Harness**。
3. 在 Agent Harness 中配置模型。
4. 从侧边栏图标或命令面板打开 MotusAI Agent。
5. MotusAI Seed 请求授权时，确认连接。

## 添加到对话

右键文件或文件夹，选择 **添加到对话**，即可将引用加入输入区。已有文字和引用会保留，准备好后再手动发送。文件夹会作为一个整体引用添加，由 Agent 按需查看其中的内容。

## 绘图与标注

在 Seed 中启用 **Canvas** 插件，然后在工作或目标模式下描述想画的图，例如“使用 Excalidraw 帮我画一个登录流程图”。点击回复中的 `.excalidraw` 文件链接，在 Obsidian 内直接编辑，无需另装 Excalidraw 社区插件。

打开图纸后，使用对话右上角的标注按钮选中图形或文字，写下修改要求，再随消息发送给 Agent。

## 调整表格列宽

在实时阅览或阅读视图中，将鼠标移到 Markdown 表头的右边缘，按住拖动即可调整列宽。双击边缘可恢复该表格的默认列宽。列宽保存在本地插件设置中，笔记的 Markdown 内容不变。可在 MotusAI Agent 设置中关闭此功能；Seed 未运行时也可使用。

## 分享为网页

在 Seed 中启用 **网页发布** 插件，插件会自动连接分享服务并在启动时恢复已有分享。右键 Markdown、图片、HTML、Canvas、Excalidraw 文件或文件夹，选择 **分享为网页**。检查文件范围与引用内容，预览后点击 **生成链接**，再在成功页点击 **复制链接**。Markdown 可选择文章主题，图片支持缩放和全屏，网页保留原样式及浏览器端脚本，画布和图纸支持只读拖动缩放。

引用的本地文件会自动一起分享，包括仓库外的引用文件，无需额外确认；其他类型的附件提供下载。新文件夹分享会自动加入后来新增的受支持文件，排除项仍然有效。已有的 Markdown 文件夹链接保留原范围，重新生成文件夹链接可加入其他受支持类型。

文档、图片和附件保留在本机，Seed 与网页发布插件保持运行和联网时，读者可通过链接访问；保存文档后可以关闭 Obsidian。预览链接十分钟后失效，正式链接可在分享面板中取消。已经被读者取得的内容无法收回。

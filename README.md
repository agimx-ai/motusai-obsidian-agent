## Work with your vault through MotusAI Seed

Bring conversations and agent-powered work into Obsidian. Use your notes, files and selected preview content as context while staying in control of every action.

## Highlights

- Generate hand-drawn flowcharts, mind maps and schematics with Excalidraw, then open and edit them in the embedded editor.
- Choose **Chat**, **Work** or **Goal** for the way you want to collaborate.
- Reference notes, files and folders without leaving your vault.
- Annotate selected preview content and send it with your message.
- Review tool activity and approve sensitive actions before they run.
- Switch between configured models and continue previous conversations.
- Share local notes or a folder as a webpage with automatic navigation and a choice of themes.

## Get started

1. Install and enable **MotusAI Agent** from Obsidian's Community Plugins.
2. Start [MotusAI Seed](https://motusseed.com), then add and enable **Agent Harness**.
3. Configure a model in Agent Harness.
4. Open MotusAI Agent from the ribbon or the command palette.
5. Approve the connection when MotusAI Seed asks.

## Add to conversation

Right-click a file or folder and choose **Add to conversation** to add its reference to the composer. Your existing text and references stay in place, and you decide when to send. A folder is added as one reference so the Agent can explore its contents as needed.

## Drawing and annotations

Enable the **Canvas** plugin in Seed, then describe a drawing in Work or Goal mode, for example “Use Excalidraw to draw a login flowchart.” Click the `.excalidraw` file link in the reply to edit it directly in Obsidian. No additional Excalidraw community plugin is required.

With a drawing open, use the annotation button at the top right of the conversation to select shapes or text, add a change request and send it with your next message.

## Share as webpage

Enable **Web Publishing** in Seed. It connects automatically and restores existing shares when Seed starts. Right-click a Markdown, image, HTML, Canvas, or Excalidraw file, or a folder, and choose **Share as webpage**. Review the files and references, preview, then select **Generate link** and **Copy link** on the success screen. Markdown supports article themes, images support zoom and fullscreen, webpages retain their styles and browser scripts, and drawings provide read-only pan and zoom.

Referenced local files, including files outside your vault, are shared automatically without extra confirmation; other attachment types are available to download. New folder shares include supported files added later, and exclusions still apply. Existing Markdown folder links retain their original scope; create a new folder link to include other supported formats.

Documents, images, and attachments stay on your computer. Keep Seed and Web Publishing running and online so readers can use the link; Obsidian can close after you save. Preview links expire after ten minutes. Published links can be cancelled in the sharing panel, but content readers already obtained cannot be recalled.
